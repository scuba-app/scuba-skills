# Scuba skills moved

Scuba skills, plugins, and MCP installation guides now live in
[scuba-plugins](https://github.com/scuba-app/scuba-plugins).

```bash
npx skills add scuba-app/scuba-plugins --skill scuba-setup scuba-codebase-memory scuba-review-memory
```

For plugin installation, platform packages, team configuration, or MCP-only setup,
use the [canonical installation guide](https://github.com/scuba-app/scuba-plugins#quick-start).

This repository is archived. Develop and install skills from scuba-plugins.
The original commits remain available here for historical reference.
